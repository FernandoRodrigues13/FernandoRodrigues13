# Olá! Eu sou o Fernando Rodrigues 👋

💻 Desenvolvedor Full Stack focado em criar sistemas web inteligentes para empresas.

Tenho experiência no desenvolvimento de sistemas corporativos, integrações com APIs, dashboards, Business Intelligence e aplicações com Inteligência Artificial.

Sempre busco aprender novas tecnologias e construir soluções modernas, seguras e escaláveis.
